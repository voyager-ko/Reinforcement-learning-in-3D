# Reinforcement Learning in 3D

Three.js（WebGPU）を使って3D空間上でロボット（車）が**Q学習**によって自動的に道路の運転を学習するシミュレーションです。

---

## 概要

ロボットはスタート地点からゴールまで道を外れずに走り切ることを目標に、試行錯誤を繰り返しながら自律的に走り方を習得します。複数台のロボットが同じQテーブルを共有することで、並列学習による高速化にも対応しています。

---

## 機能

- **Q学習によるロボットの自律走行** — 試行錯誤を繰り返してゴールへの経路を習得
- **複数台の並列学習** — 最大8台が同一Qテーブルを共有し、学習を加速
- **迷路ビルダー** — 5×5グリッドで道路形状を自由に設計して3Dに適用
- **リアルタイム学習状況表示** — 試行回数・成功率・探索率などをUIでリアルタイム確認
- **学習の引き継ぎ** — 台数やパラメータを変更してもQテーブル・εを継続
- **カメラ操作** — マウスドラッグで視点回転、WASD/EQキーで移動

## 操作方法

### カメラ操作

| 操作 | 動作 |
|---|---|
| マウスドラッグ | 視点の回転 |
| `W` / `S` | 前進 / 後退 |
| `A` / `D` | 左移動 / 右移動 |
| `E` / `Q` | 上昇 / 下降 |
| `G` | カメラ位置をコンソールに出力 |

### UIパネル（右上のボタンをクリックして開く）

| 設定項目 | 説明 |
|---|---|
| 台数スライダー | 同時に走らせるロボットの台数（1〜8台） |
| 学習率 α | Q値の更新速度（0.01〜0.5） |
| 割引率 γ | 将来の報酬をどれだけ重視するか（0.5〜0.99） |
| 台数・設定を変更 | Qテーブルを引き継いで設定を変更する |
| 学習をリセット | Qテーブルを初期化して最初から学習しなおす |
| 迷路を設定 | 道路形状を5×5グリッドで設計する |

## Q学習の実装

### アルゴリズムの概要

Q学習は「状態 → 行動 → 報酬」のサイクルを繰り返すことで、各状況における最適な行動を表す **Qテーブル** を構築していく強化学習アルゴリズムです。

```
Q(s, a) ← Q(s, a) + α × [ r + γ × max Q(s', a') − Q(s, a) ]
```

| 記号 | 変数名 | 値 | 意味 |
|---|---|---|---|
| α | `this.alpha` | 0.12 | 学習率（Q値の更新速度） |
| γ | `this.gamma` | 0.97 | 割引率（将来の報酬の重み） |
| ε | `this.epsilon` | 1.0 → 0.045 | 探索率（ランダム行動の確率） |

---

### 1エピソードの流れ

```
スタート地点に配置
    ↓
現在の状況を状態キーに変換（encodeState）
    ↓
行動を選択：左 / 直進 / 右（chooseAction — ε-greedy）
    ↓
ロボットを移動し報酬を計算（moveRobot → calculateReward）
    ↓
Q値を更新（updateQ）
    ↓
エピソード終了判定（道外れ / 時間切れ / ゴール到達）
    ↓ YES
ε を更新して次のエピソードへ（finishEpisode）
```

---

### 成功率の目安

| 成功率 | 状態の目安 |
|---|---|
| 0〜20% | 学習初期。まだほぼランダムに動いている段階。 |
| 20〜50% | 学習が機能し始めている。道の序盤は走れるようになってきた。 |
| 50〜80% | 安定して走れるようになりつつある段階。 |
| **80% 以上** | **実用的なレベル。ほぼ毎回ゴールまで走れる。** |
